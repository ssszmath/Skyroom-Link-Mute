افزونه Skyroom Link Mute - نسخه 1.2.0

نصب:
1) فایل ZIP را از حالت فشرده خارج کنید.
2) در Chrome وارد chrome://extensions شوید.
3) Developer mode را روشن کنید.
4) روی Load unpacked بزنید.
5) پوشه skyroom-link-mute را انتخاب کنید.
6) صفحه اتاق Skyroom را تازه‌سازی کنید.

استفاده:
- روی آیکون افزونه کلیک کنید.
- کلید «محافظت از چت» را روشن کنید.
- پیام‌های جدید کاربران دیگر که حاوی لینک یا آیدی کانال (@username) باشند بررسی می‌شوند.
- اگر فرستنده از قبل ساکت نشده باشد، منوی پیام باز و گزینه «ساکت کردن کاربر» انتخاب می‌شود.
- خاموش کردن کلید، پردازش پیام‌های بعدی را متوقف می‌کند.
- دکمه «ریست کردن شمارنده»، تعداد عملیات موفق را در این مرورگر صفر می‌کند.

نکات:
- نسخه 1.2.0: دکمه ریست شمارنده اضافه شد.
- نسخه 1.1.0: تشخیص آیدی کانال (مثل @mathteacher) اضافه شد.
- شمارنده، تعداد عملیات موفق این افزونه را در این مرورگر نگه می‌دارد؛ الزاماً تعداد کل کاربران ساکت‌شده در اتاق نیست.
- برای تشخیص تیک، قابل‌مشاهده بودن .checked-icon بررسی می‌شود.
- افزونه فقط روی https://www.skyroom.online اجرا می‌شود.
