## 📖 معرفی

**Skyroom Link Mute** یک افزونه مرورگر Chrome است که به‌طور خودکار کاربرانی را که در چت اسکای‌روم لینک یا آیدی کانال ارسال می‌کنند، ساکت می‌کند. این افزونه به معلمان و مدیران کلاس کمک می‌کند تا از اسپم و ارسال لینک‌های ناخواسته در چت جلوگیری کنند.

### ✨ ویژگی‌ها

- 🔗 **تشخیص لینک**: شناسایی خودکار لینک‌های HTTP/HTTPS و آدرس‌های وب در پیام‌ها
- 📢 **تشخیص آیدی کانال**: شناسایی آیدی کانال‌ها با فرمت `@username` (مثلاً `@mathteacher`)
- 🔇 **ساکت کردن خودکار**: کلیک خودکار روی منوی پیام و انتخاب گزینه ساکت کردن
- 📊 **شمارنده عملیات**: نمایش تعداد عملیات موفق ساکت کردن
- 🔄 **دکمه ریست**: امکان صفر کردن شمارنده در هر مرورگر
- ⚡ **فعال/غیرفعال**: کنترل کامل با یک کلید ساده

## 🚀 نصب

### روش ۱: نصب از فایل ZIP

1. فایل ZIP را از حالت فشرده خارج کنید.
2. در مرورگر Chrome وارد `chrome://extensions` شوید.
3. حالت **Developer mode** را در گوشه بالا سمت چپ روشن کنید.
4. روی دکمه **Load unpacked** کلیک کنید.
5. پوشه `skyroom-link-mute` را انتخاب کنید.
6. صفحه اتاق اسکای‌روم را تازه‌سازی کنید.

### روش ۲: نصب از GitHub

```bash
# کلون کردن مخزن
git clone https://github.com/username/skyroom-link-mute.git
cd skyroom-link-mute

# سپس مراحل ۲ تا ۶ روش بالا را دنبال کنید
```

## 📱 نحوه استفاده

1. روی آیکون 🛡️ افزونه در نوار ابزار Chrome کلیک کنید.
2. کلید **«محافظت از چت»** را روشن کنید.
3. افزونه به‌طور خودکار پیام‌های جدید را بررسی می‌کند:
   - اگر پیام حاوی **لینک** باشد → فرستنده ساکت می‌شود
   - اگر پیام حاوی **آیدی کانال** باشد → فرستنده ساکت می‌شود
4. تعداد عملیات موفق در popup نمایش داده می‌شود.
5. برای متوقف کردن، کلید را خاموش کنید.

### ⚙️ تنظیمات

| گزینه | توضیحات |
|--------|----------|
| **محافظت از چت** | روشن/خاموش کردن پردازش پیام‌ها |
| **ریست شمارنده** | صفر کردن تعداد عملیات موفق در این مرورگر |

## 🔍 نحوه کار

```
پیام جدید چت
    │
    ├── بررسی لینک (HTTP/HTTPS/www)
    │       │
    │       ├── پیدا شد → ساکت کردن
    │       │
    │       └── پیدا نشد
    │               │
    │               ├── بررسی آیدی کانال (@username)
    │               │       │
    │               │       ├── پیدا شد → ساکت کردن
    │               │       │
    │               │       └── پیدا نشد → بدون عمل
    │               │
    │               └── بدون عمل
```

### جزئیات فنی

- **MutationObserver**: رصد لحظه‌ای تغییرات DOM برای شناسایی پیام‌های جدید
- **تشخیص لینک**: بررسی تگ‌های `<a>` و متن خام پیام با regex
- **تشخیص آیدی کانال**: regex `/@[a-z0-9_]{2,}/i` برای شناسایی آیدی‌ها
- **جلوگیری از تکرار**: استفاده از `Set` برای پیگیری پیام‌های پردازش‌شده
- **ذخیره‌سازی**: استفاده از `chrome.storage.local` برای نگهداری وضعیت و شمارنده
