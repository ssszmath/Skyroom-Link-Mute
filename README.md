> **ساکت کردن فرستندهٔ پیام‌های حاوی لینک یا آیدی کانال، با امکان حذف اختیاری پیام در چت اسکای‌روم**

## 📖 معرفی

**Skyroom Link Mute** یک افزونه مرورگر Chrome است که به‌طور خودکار کاربرانی را که در چت اسکای‌روم لینک یا آیدی کانال ارسال می‌کنند، ساکت می‌کند. حذف همان پیام نیز با یک گزینهٔ مستقل در پنجرهٔ افزونه قابل فعال‌سازی است و به‌صورت پیش‌فرض خاموش است. این افزونه به معلمان و مدیران کلاس کمک می‌کند تا از اسپم و ارسال لینک‌های ناخواسته در چت جلوگیری کنند.

### ✨ ویژگی‌ها

- 🔗 **تشخیص لینک**: شناسایی خودکار لینک‌های HTTP/HTTPS و آدرس‌های وب در پیام‌ها
- 📢 **تشخیص آیدی کانال**: شناسایی آیدی کانال‌ها با فرمت `@username` (مثلاً `@mathteacher`)
- 🔇 **ساکت کردن خودکار**: کلیک خودکار روی منوی پیام و انتخاب گزینه ساکت کردن
- 🗑️ **حذف اختیاری پیام**: با روشن‌کردن سوییچ جداگانه، گزینهٔ حذف انتخاب و دیالوگ تأیید همان پیام به‌صورت خودکار تأیید می‌شود
- 📊 **شمارنده عملیات**: نمایش تعداد عملیات موفق ساکت کردن
- 🔄 **دکمه ریست**: امکان صفر کردن شمارنده در هر مرورگر
- ⚡ **فعال/غیرفعال**: کنترل کامل با یک کلید ساده

## 🚀 نصب

### روش ۱: نصب از فایل ZIP

1. فایل ZIP را از حالت فشرده خارج کنید.
2. در مرورگر Chrome وارد `chrome://extensions` شوید.
3. حالت **Developer mode** را در گوشه بالا سمت چپ روشن کنید.
4. روی دکمه **Load unpacked** کلیک کنید.
5. پوشه `skyroom-link-mute` را انتخاب کنید.
6. صفحه اتاق اسکای‌روم را تازه‌سازی کنید.

### روش ۲: نصب از GitHub

```bash
# کلون کردن مخزن
git clone https://github.com/username/skyroom-link-mute.git
cd skyroom-link-mute

# سپس مراحل ۲ تا ۶ روش بالا را دنبال کنید
```

## 📱 نحوه استفاده

1. روی آیکون 🛡️ افزونه در نوار ابزار Chrome کلیک کنید.
2. کلید **«محافظت از چت»** را روشن کنید.
3. در صورت تمایل، کلید **«حذف خودکار پیام»** را نیز روشن کنید؛ این گزینه به‌طور پیش‌فرض خاموش است.
4. افزونه به‌طور خودکار پیام‌های جدید را بررسی می‌کند:
   - اگر پیام حاوی **لینک** یا **آیدی کانال** باشد → فرستنده ساکت می‌شود و در صورت فعال بودن گزینهٔ حذف، دیالوگ تأیید حذف همان پیام نیز به‌صورت خودکار تأیید می‌شود.
   - اگر فرستنده از قبل ساکت باشد، فقط در صورت فعال بودن حذف پیام، آن پیام حذف می‌شود.
5. تعداد عملیات جدید ساکت کردن در popup نمایش داده می‌شود.
6. برای متوقف کردن، کلید محافظت را خاموش کنید.

### ⚙️ تنظیمات

| گزینه | توضیحات |
|--------|----------|
| **محافظت از چت** | روشن/خاموش کردن پردازش پیام‌ها |
| **حذف خودکار پیام** | در صورت روشن بودن، دیالوگ تأیید حذف پیام دارای لینک یا آیدی کانال به‌صورت خودکار تأیید می‌شود؛ پیش‌فرض خاموش است |
| **ریست شمارنده** | صفر کردن تعداد عملیات موفق در این مرورگر |

## 🔍 نحوه کار

```
پیام جدید چت
    │
    ├── بررسی لینک (HTTP/HTTPS/www)
    │       │
    │       ├── پیدا شد → ساکت کردن؛ حذف پیام در صورت فعال بودن گزینه
    │       │
    │       └── پیدا نشد
    │               │
    │               ├── بررسی آیدی کانال (@username)
    │               │       │
    │               │       ├── پیدا شد → ساکت کردن؛ حذف پیام در صورت فعال بودن گزینه
    │               │       │
    │               │       └── پیدا نشد → بدون عمل
    │               │
    │               └── بدون عمل
```

### جزئیات فنی

- **MutationObserver**: رصد لحظه‌ای تغییرات DOM برای شناسایی پیام‌های جدید
- **تشخیص لینک**: بررسی تگ‌های `<a>` و متن خام پیام با regex
- **تشخیص آیدی کانال**: regex `/@[a-z0-9_]{2,}/i` برای شناسایی آیدی‌ها
- **جلوگیری از تکرار**: استفاده از `Set` برای پیگیری پیام‌های پردازش‌شده و صف‌بندی عملیات منو
- **ذخیره‌سازی**: استفاده از `chrome.storage.local` برای نگهداری وضعیت، گزینهٔ حذف و شمارنده
